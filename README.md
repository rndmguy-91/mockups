# Mockups

## Planner prototype

Single-file clickable prototype of the kitchen planner (`planner-prototype/index.html`). All images, logos and icons are embedded, so the file works on its own; `planner-prototype/logos/` holds the source PNGs.

Open in the browser (rendered page):

- GitHub Pages (after Pages is enabled for `main` / root): https://rndmguy-91.github.io/mockups/planner-prototype/
- Without Pages: https://raw.githack.com/rndmguy-91/mockups/main/planner-prototype/index.html

`raw.githubusercontent.com` serves HTML as plain text, so a raw link shows the source instead of the page.

Options for testing: `?prices=0` hides prices, `?articles=0` hides the article list.
